# Daily evolution health

> Health on this page is authoritative.

Clone default is `lamp: running`. The timer is on. Paste your `*_API_KEY` on [[自进化钥匙]], or log in `grok` / official Codex / `claude` once. Distill does not run until one of those is set. `lamp: unused` means you turned the timer off.

`status` prints `host_action` while `self_evolution_key` or `krouter_writer` is `missing`. The mounted agent must tell the host. Never put keys on this page.
