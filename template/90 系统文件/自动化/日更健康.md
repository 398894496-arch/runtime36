# Daily evolution health

> Health on this page is authoritative.

Clone default is `lamp: running`. The timer is on. Fill an API key or subscription env vars — that is the self-evolution key. Pin `KROUTER_WRITER`. Distill does not run until both are set. `lamp: unused` means you turned the timer off.

`status` prints `host_action` while `self_evolution_key` or `krouter_writer` is `missing`. The mounted agent must tell the host. Never put keys on this page.
