# Self-evolution key

This page **is** the config. The timer reads it. There is no second env file and nothing to pin.

Do **not** commit a live key. The clone ships placeholders only.

## Already logged in (subscription)

If `grok login`, official Codex (`/Applications/ChatGPT.app/Contents/Resources/codex`), or `claude auth login` already works on this machine, stop here. The daily job auto-detects that CLI and distills. Chat/IDE login is not the timer. A PATH-level `agent` is refused.

Also auto-detected when logged in: `opencode`, `kimi`, `pi`, `vibe`, `antigravity`, Cursor CLI (`~/.cursor/bin/cursor-agent`).

## Or paste your API key

Uncomment **one** line. Any mainstream `*_API_KEY` works. Unnamed OpenAI-compatible endpoints also set `OPENAI_BASE_URL`.

# OPENAI_API_KEY=YOUR_OPENAI_API_KEY
